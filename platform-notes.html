Platform notes

The API is the same on every Scala version and platform. These are the places where they differ.

Scala 2 and Scala 3

On Scala 2, the argument types such as Key and PosInt come from refined. On Scala 3, they come from Iron. Code that uses them through LaserDisc, with from, unsafeFrom and .value, works on both.

If you write your own refined types for use with LaserDisc, write them with refined on Scala 2 and with Iron on Scala 3.

Scala.js and Scala Native

laserdisc-core, laserdisc-circe, laserdisc-fs2 and laserdisc-cli work on the JVM, Scala.js and Scala Native.

On Scala.js, laserdisc-fs2 and laserdisc-cli run on Node.js, not in browsers, because they need network sockets.

On Node.js 26, the connection can stop receiving replies when several arrive at once. The commands waiting for those replies time out, and the client then reconnects on its own. Node.js 25 and earlier aren't affected.
